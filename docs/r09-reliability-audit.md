# R-09 reliability audit and QA foundation

Scope: source review of the aggregate deployment and Race Desk checks at base `2fe5679c`. This is a coverage assessment, not certification of production, external providers, or future releases. The ecosystem dry run is a read-only rehearsal; the live API read is informational and is not a release gate.

| Failure case | Existing evidence and behavior | Remaining verification |
| --- | --- | --- |
| Missing pages, assets and mappings | Assembly rejects missing tool roots, chunks and assets; public integrity checks sitemap pages. Smoke checks unknown tool paths and the GP browser suite checks an unknown GP 404. Link tests check missing race/provider mappings and generic fallback. | Exercise every published deep link against the assembled artifact; a sitemap check is not a complete link crawl. Static test servers do not prove GitHub Pages' deployed 404 behavior. |
| Legacy URLs | Link/parser and browser tests cover representative legacy URLs. `redirects.mjs` prepares path-preserving stubs, with query/hash preserved by JavaScript; tests execute a fallback stub. | Stubs are preparation only and not proof of deployment to old sites. With JavaScript disabled, meta refresh and the link use the fixed target, so query/hash and unknown deep-path preservation are not established. Verify actual old hosts and no-JS behavior before claiming compatibility. |
| Provider timeout or 429 | Navigation browser fixtures simulate 503 failures; live-read has a 20-second timeout and marks non-2xx responses unreadable. The deterministic integration smoke records successful API responses. | No end-to-end timeout or 429 injection across each tool, retry/backoff, recovery, or reader-facing failure state is certified. Live-read is a point-in-time connectivity/CORS probe, not a data correctness check. |
| Partial, stale, or uncertified data | Missing TYRES manifest and stale snapshot fail assembly; an old or missing current forecast is a warning, not a release failure. Registry/model tests cover missing mappings, partial schedules and invalid claims. | Fresh manifest time alone does not prove complete, accurate or certified data. Forecast warnings do not block release. Cross-provider partial responses, contradictory results and certification status require explicit contracts and failure-injection tests. |
| DST and time zones | Hub model tests cover Athens DST gap/fold and midnight; browser checks compare displayed session times in UTC, venue and Athens zones. | Fixture cases do not establish correctness for every future transition, venue, or runtime timezone database version. |
| No JavaScript | GP browser suite loads each pilot page with JS disabled, checks content, links, times and reload. | This does not cover the interactive child tools or legacy redirect query/hash behavior without JS. |
| Themes | GP browser suite tests light/dark across four widths; aggregate smoke exercises theme and navigation flows. | Visual screenshots and selected assertions are not complete contrast or accessibility certification, nor proof across all pages and browsers. |
| GP routes | GP browser suite tests direct load, reload, unknown route and published pilot pages; Site Quality runs it on non-content-only changes, and ecosystem dry run runs it on the assembled artifact. | Dry run is path-filtered and not run for every PR. Production deployment and all possible deep routes are not covered by these checks. |
| Leakage | Assembly tests reject credential-like files, source maps, internal docs, test content and symlinks; hub browser checks restrict expected provider requests. | Filename/path rules and request assertions cannot prove absence of secrets in arbitrary content, logs, screenshots or unexpected runtime channels. Review artifacts and network traffic separately. |

The dry-run workflow uploads diagnostics and never publishes. Site Quality runs contract and deployment unit tests for all PRs, while its browser checks are skipped for content-only changes. The full pinned aggregate build and browser tests require the ecosystem workflow and its toolchains; this audit does not claim those were run locally.
