# P-01 compact evidence data

From a checkout root, run `python3 <R>/work/data/package-data.py` and `python3 <R>/work/data/check-data.py`; R is the extraction root containing evidence and work, and the checkout supplies docs/performance and perf/p01. The packager also reads the checkout perf budget files and R/evidence-bundle.json. Retained evidence is on the owner’s machine outside git; obtain the archive matching the SHA-256 in evidence-index.json. Resolve an entry using `local-bundle:p01-evidence.tar.gz#<entry path>`. Evidence files may contain sensitive raw material and require review before sharing.

`baseline.json` identifies pinned release, budgets and tools. `matrix.json` records routes, profiles, planned counts and actual attempts. `runs.jsonl` retains one row per CDP/interaction attempt or Lighthouse observation; timestamps, fixture/config IDs and API modes are null where absent in source. Metrics are arrays with fixed order: CDP/interaction fcp, lcp, cls, dom_nodes, request_count, ScriptDuration, LayoutDuration, RecalcStyleDuration, TaskDuration, event_duration_ms, interaction_latency_ms; Lighthouse performance, accessibility, best-practices, seo, fcp, lcp, tbt, si, cls. Values retain null; fcp/lcp/tbt/si/event_duration_ms/interaction_latency_ms use ms, ScriptDuration/LayoutDuration/RecalcStyleDuration/TaskDuration use seconds, dom_nodes and request_count are counts, and cls and Lighthouse categories are scores. `summary.tsv` has one metric per series/cell with median, min, max and valid/attempted n. `resources.tsv` is the network schema plus environment; `interactions.tsv` uses LAB values, not field INP; `cache.tsv` describes cache observations. Remaining TSVs preserve the named worker schemas; `artifact-summary.tsv` groups the artifact inventory by owner and classification. Findings retain the authoritative source unchanged. `checks.tsv` includes the aggregate runtime check; `gates.json` records only supported verdicts.

Production and local-built are independent series; other worker inventories are source/build inventories and are not runtime series. Null means not measured or not supplied, never zero. Units appear in column names or adjacent unit fields; sizes are bytes and timings milliseconds unless stated otherwise. Standings tab-pit-stops and session are NOT MEASURED because controls were not ready or missing, as recorded per row.

Reductions: summary evidence-ID lists are replaced by EV-RUNTIME, referring to the complete retained runtime.tsv; all numerical rows remain intact except the always-null event_duration_ms and interaction_latency_ms rows (452 rows), plus 360 interaction-method summary rows whose statistics are all null; all are in retained runtime.tsv. Resources include at most the three largest transferred resources plus the first null/failed HTTP status per first observed run in each environment/series/method/route/device/theme/cache cell, plus the 25 largest transfers overall and all observed redirects; all other request rows remain in retained network.tsv. Runs omit verbose assertion arrays, console logs and repeated Lighthouse configuration; source JSONL retains them. Artifact rows are reduced to owner/classification counts and byte totals; the per-file inventory remains outside this package. Partner asset filenames use stable aliases P1–P6. URL queries are stripped except public OpenF1/Jolpica API parameters; local paths and contact identifiers are redacted. No source series were merged. Pilot and pre-rerun files were excluded. The index lists evidence JSONL/TSV, Gate logs and cited members individually. Remaining files are grouped as traces, Lighthouse JSON, child source snapshots, logs or other; each group records count, total bytes and SHA-256 of UTF-8 lines `hash  path` sorted by path, each terminated by a newline. AppleDouble files are excluded from the archives. The companion p01-local-site.tar.gz contains the frozen artifact.

Digests are written `sha256-<hex>` because Main's static source guard bans the colon form. The retained `package-data.py` still emits the colon form; apply the same substitution after regenerating.
