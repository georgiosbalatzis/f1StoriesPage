# Απολογισμός συντακτικού πειράματος

Δημόσιο πρότυπο χωρίς πραγματικά analytics πλήθη, αναζητήσεις, δεδομένα επισκεπτών ή αποκρυπτογραφημένα στοιχεία.
Οι πραγματικές μετρήσεις παραμένουν στην ιδιωτική διαδικασία του υπευθύνου· εδώ δημοσιεύεται μόνο ασφαλής απόφαση και περιορισμοί.

- **ID και υπεύθυνος:** …
- **Ημερομηνία ανασκόπησης (`YYYY-MM-DD`) και actor:** …
- **PR/commit της αλλαγής:** …
- **Αρχική υπόθεση και τι άλλαξε:** …
- **Τρέχον status / προτεινόμενο επόμενο status:** …

## Συγκρισιμότητα και επάρκεια

- **baselinePeriod:** start … / end …
- **comparisonPeriod:** start … / end …
- **Ημέρα αναφοράς και χρονική ζώνη πηγών:** …
- **Ίσο μήκος και χωρίς επικάλυψη:** PASS / FAIL / NOT VERIFIED — αιτιολόγηση …
- **Ώριμο τέλος (υποχρεωτικό μόνο για COMPLETED):** PASS / FAIL / NOT VERIFIED — αιτιολόγηση· INCONCLUSIVE και ROLLED_BACK επιτρέπονται πριν από την ωρίμανση …
- **primaryOutcome metric / unit / source / population:** …
- **Ίδια φίλτρα και κάλυψη στις δύο περιόδους:** PASS / WARNING / FAIL / NOT VERIFIED — περιορισμοί …
- **evidenceFloor ανά περίοδο (προεπιλογή 30):** …
- **Επάρκεια σε καθεμία περίοδο, χωρίς δημοσίευση πραγματικών πληθών:** PASS / WARNING / FAIL / NOT VERIFIED — αιτιολόγηση …
- **Εβδομαδιαία ή μεταφερόμενα δεδομένα:** πραγματική περίοδος και περιορισμοί, χωρίς χαρακτηρισμό «σημερινά» …
- **Παραγωγική συμφωνία δεδομένων:** PASS μόνο αν ελέγχθηκε από εξουσιοδοτημένο υπεύθυνο· διαφορετικά NOT VERIFIED …

Το PASS αφορά τον συγκεκριμένο έλεγχο, όχι επιτυχία πειράματος. Το WARNING δηλώνει γνωστό περιορισμό,
το FAIL αποδεδειγμένη παράβαση και το NOT VERIFIED έλλειψη ελέγχου/τεκμηρίωσης.
Το μητρώο ελέγχει μόνο το σχήμα, όχι τις πραγματικές μετρήσεις.

## Ανθρώπινη απόφαση

- **Εφαρμογή της αρχικής decisionPolicy:** …
- **Απόφαση:** διατήρηση / παύση / επαναφορά / INCONCLUSIVE …
- **Νέο status:** COMPLETED (ολοκλήρωση ανασκόπησης, όχι απόδειξη επιτυχίας), INCONCLUSIVE, PAUSED ή ROLLED_BACK, μόνο αν επιτρέπεται από το history …
- **Περιορισμοί και λόγος απόφασης:** …
- **Επαναφορά, αν έγινε:** ακριβή βήματα, έλεγχοι και PR/commit …
- **Νέα εγγραφή history:** status … / date … / actor … / note … / pr ή commit (υποχρεωτικό για ROLLED_BACK) …

Προσθέστε την εγγραφή στο τέλος και ενημερώστε το status. Μην ξαναγράφετε το παρελθόν ή χαμηλώνετε εκ των υστέρων το evidenceFloor.
Με ανεπαρκή ή μη συγκρίσιμα δεδομένα επιλέγουμε INCONCLUSIVE. Μια αρνητική ένδειξη guardrail μπορεί να δικαιολογεί
ανθρώπινη επαναφορά χωρίς να αποδεικνύει αιτιότητα. Δεν βαφτίζουμε συμβάντα GA4 «αναγνώστες», GSC clicks «page_views»
ή εσωτερικά κλικ «φορτώσεις». Περίπου 5 consented επισκέπτες/ημέρα: η σύγκριση πριν/μετά παραμένει παρατηρησιακή.
Κανένα αποτέλεσμα δεν ενεργοποιεί αυτόματη δημοσίευση, εξωτερική ανάρτηση, αλλαγή GA4/tracking ή A/B test.
